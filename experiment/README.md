# 실험 디렉터리 상태와 실행 전 안내

현재 제목은 [RESEARCH_TITLE.txt](../RESEARCH_TITLE.txt), 본실험 기준은 [최종 설계](../docs/RESEARCH_PLAN.md)다.

이 디렉터리는 `feature3`의 **과거 R/G 준비 코드와 산출물**을 보존한다. 기존 `build.py`·`run_training.py`가 새 0%·50A·50B·100% 실험을 실행한다고 해석하지 않는다. 이번 문서 변경에서 실행 코드를 수정하거나 새 본학습을 수행하지 않았다.

## 아직 필요한 구현

- 그룹 단위 고정 split/A-B, 검수 완료 GT, 독립 대조 매핑·원본 제외·반전 슬롯.
- 네 조건·세 시드의 입력/출력 분리, 공통 학습 설정·last.pt, 금지 유입·실제 목록 검사.
- 전체 이미지별 완료 상태·낮은 confidence 박스 저장·0개 예측/실패 구분.
- Val 임계값·mAP/MAE/FP/FN·동일 A/B 비교·그룹 부트스트랩·결과 재현.
- 작은 예제 및 실제 최종 입력의 짧은 전 과정 검산.

서승덕이 학습·평가 코드를, 박도현이 생성 코드를 맡고 서로 검산을 돕는다. 구현 후 검증된 명령과 실제 코드/데이터 버전을 여기에 추가한다. 지금은 새 본실험 실행 명령을 제공하지 않는다.

## 기존 자료 재사용

이전 서버 환경·로그·가중치 정보를 시간·경로 확인에 먼저 활용한다. GPU 현재 가용량은 별도 확인한다. 기존 가중치를 새 초기 가중치로 임의 승계하지 않는다. 이전 예비 실행을 새 12회 실험으로 계산하지 않는다.

[과거 feature3 실행 안내·준비 기록](https://github.com/miseplastic/firstmise/blob/64cde3258e6370893aa9f059e2fba8096ba4d3c8/experiment/README.md)은 당시 코드와 R/G 자료를 재현할 때만 사용한다. [현재 상태표](../docs/IMPLEMENTATION_STATUS.md)와 [일정](../docs/SCHEDULE.md)을 확인한다.
