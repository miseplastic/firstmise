# 최종 연구 설계

**연구 제목: 미세플라스틱 객체 탐지에서 데이터 누수가 탐지 성능과 입자 계수 오차에 미치는 영향 — 시험 이미지 반전본의 학습 노출 실험**

기준일: 2026-11-26. 아래는 확정된 설계이며 실행 완료 보고가 아니다. [상태표](IMPLEMENTATION_STATUS.md)와 [설계 PDF](pdf/research-design.pdf)를 함께 읽는다.

## 1. 질문·기여·범위

반전본 학습 노출에 따른 탐지 점수 변화가 어떤 사진과 오류에서 나타나며, 입자 계수 정확도의 변화와도 일치하는가?

누수가 점수에 영향을 준다는 사실이나 노출 사진의 상승 자체를 참신성으로 주장하지 않는다. 동일 평가 자료·통제된 교체 조건에서 변화 위치와 누락·오탐·계수 오류를 연결하고 재현 가능한 근거를 남긴다. 미노출로의 전파 기전, 배경 암기, 독립 새 사진의 일반화, 과거 G>R의 원인, 농도·고유 물리 입자 수를 입증하지 않는다.

## 2. 데이터·그룹·분할

- 기본 자료는 781장·7,126박스·한 클래스. 원본 train/valid 폴더는 출처 구분이다.
- 그룹 판정 → 그룹 단위 Train/Val/Test → Test 그룹 단위 A/B를 고정한다. 그룹을 절반 장수 때문에 쪼개지 않는다. 분할·A/B는 모든 학습 시드에 공통이다.
- 관계는 완전 중복·변환본·연관 촬영 추정·독립·불확실로 기록한다. 파일명·배경·유사도 하나로 확정하지 않는다. 미해결 관계는 보수적 배치와 사실 판정을 구분한다.
- Test 전체, Val, 선택 대조의 GT를 공통 포함 기준으로 검수한다. 알려진 Train 오류도 처리하고 검수 범위를 기록한다. 판단 불가능 건은 성능을 보기 전에 처리 방침을 정한다.
- Test GT 수정은 노출용 반전 라벨에도 반영한다. 모든 평가 조건은 같은 이미지 ID·GT 버전이다.
- 자연 촬영 쌍을 Test에 강제로 고정하는 것은 필수가 아니다. 의도적으로 넣으면 이유·제외 민감도를 보고하고 배경 암기 증거로 확대하지 않는다.

## 3. 네 조건과 대조

공통 Train에서 모든 대응 대조 원본을 제외하고 같은 수의 슬롯을 만든다. 각 Test 사진에 독립 Train 대조 하나를 대응시킨다. 객체 수·크기 등을 고려하고 후보 검수 후 수정 GT로 매핑을 고정한다.

| 조건 | A 자리 | B 자리 |
|---|---|---|
| 0% | 대조 반전본 | 대조 반전본 |
| 50A | Test A 반전본 | 대조 반전본 |
| 50B | 대조 반전본 | Test B 반전본 |
| 100% | Test A 반전본 | Test B 반전본 |

학습 장수·슬롯·반전·저장 처리를 맞추고 객체 수·크기·그룹 구성 차이를 공개한다. 시험 노출률과 학습 중 노출 자료 비율의 분모를 구분한다. 100%는 Test 전체를 노출했다는 뜻이다. 교체 효과와 순수 누출 효과가 완전히 분리되지는 않는다.

## 4. 학습 설정

| 항목 | 설계 기준 |
|---|---|
| 모델·초기 가중치 | YOLOv5s, 동일 초기 파일·해시 |
| 입력·배치·학습량 | 640 / batch 4 / 30에포크, 조기 종료로 단축하지 않음 |
| 시드·횟수 | 101·102·103 × 네 조건 = 12회 |
| 앵커·증강 | 동일 앵커, AutoAnchor 끔, fliplr=0, 나머지 공통 설정 |
| 주 평가 모델 | 30에포크 종료 last.pt. best.pt는 별도 보조로만 구분 |

같은 시드가 학습 구성 차이·교체 효과를 모두 상쇄한다고 가정하지 않는다. 기존 로그로 시간·환경을 먼저 확인하고 조건이 크게 다를 때 추가 측정한다.

## 5. 지표·임계값·예측 저장

- 핵심: mAP@50:95(높을수록 좋음), 사진별 계수 MAE(낮을수록 좋음). 보조 mAP@50, FP/FN, 평균 signed count error.
- 각 시드 0% 모델의 고정 Val에서 confidence 0.05~0.95, 간격 0.05로 MAE 최소값을 고른다. 동률이면 낮은 값. 같은 시드 네 조건에 공통 적용한다. 모델별 Val 선택값도 민감도 분석으로 보고한다. Test로 선택하지 않는다.
- mAP: 동일 평가 버전, v7.0 기준 conf=0.001, NMS IoU=0.6, max_det=300을 설정에 남기고 상한 도달을 확인한다.
- FP/FN: 같은 예측·GT에서 IoU 0.5, 일대일 매칭 함수·버전 고정. 기본 혼동행렬이나 최대 F1의 P/R을 그대로 쓰지 않는다.
- 낮은 평가 필터의 박스·클래스·confidence와 전체 이미지 실행 상태를 저장한다. save_hybrid는 끈다. 평가 실패와 0개 예측을 구분하고 전체 Test 목록을 분모로 집계한다.

$$\mathrm{MAE}=\frac{1}{N}\sum_{i=1}^{N}|\hat{n}_i-n_i|,\qquad \mathrm{Bias}=\frac{1}{N}\sum_{i=1}^{N}(\hat{n}_i-n_i)$$

$$\hat{n}_i-n_i=\mathrm{FP}_i-\mathrm{FN}_i$$

마지막 식은 같은 예측·GT의 일대일 매칭 기준이다. FP와 FN이 상쇄되어 개수만 맞을 수 있으므로 탐지 오류와 함께 해석한다.

## 6. 비교와 해석

주 비교는 같은 Test 전체의 100%-0%다. 50A-0%, 50B-0%를 A와 B 각각에서 보고, 직접 교환 비교도 계산한다. mAP의 차이는 %p, MAE 차이는 개/이미지로 표시한다.

$$\Delta m=m_{100,T}-m_{0,T},\qquad\Delta a=a_{100,T}-a_{0,T}$$

$$C_A=m_{50A,A}-m_{50B,A},\qquad C_B=m_{50B,B}-m_{50A,B}$$

$$D_A=(m_{50A,A}-m_{0,A})-(m_{50A,B}-m_{0,B})$$

$$D_B=(m_{50B,B}-m_{0,B})-(m_{50B,A}-m_{0,A})$$

$$\frac{D_A+D_B}{2}=\frac{C_A+C_B}{2}$$

m은 0-1 척도 mAP, a는 MAE, T는 전체 Test다. m 차이의 %p 표시는 100을 곱한다. 오류 지표의 직접 비교는 같은 순서로 계산하고 음수가 감소다. D는 보조이며 실제 변화와 함께 보고한다. 둘 다 하락해도 D가 양수일 수 있다. C 평균과 D 평균은 독립 증거가 아니다.

전체 그래프 → A/B 교환표 → 동일 사진의 GT·예측·오류 순서로 설명한다. 개선·악화·변화 작은 사례를 함께 제시한다. mAP는 가산적이지 않으므로 부분 mAP를 합쳐 전체 기여율로 해석하지 않는다. 조건 평균 몇 개로 mAP-MAE 상관을 입증하지 않는다. 메타데이터별 추가 분석은 사전 기준을 남기거나 탐색으로 표시한다.

## 7. 불확실성과 결과 선택 방지

- 시드별 원값·대응 차이·평균·표본 표준편차를 모두 보고한다. 3시드는 정밀도 보장이 아니다.
- 같은 그룹을 통째로 복원추출하고 비교 모델에 같은 표본을 적용한다. A/B 분석은 각 묶음 안에서 그룹을 재표집한다. 반복 그룹도 횟수대로 반영하며 mAP를 다시 계산한다.
- 각 학습 시드별 2,000회, 재표집 난수 20261124, 차이의 2.5/97.5 백분위 구간. 생성 표본 목록을 저장한다. 독립 그룹 2개 미만이면 해당 구간은 보고하지 않고 작은 그룹 수의 한계를 밝힌다.
- 구간은 고정 모델·confidence의 평가 표본 변동이다. 시드·임계값 선택·다른 분할 변동을 모두 포함하지 않는다.
- 상승·하락·불확실 모두 보고한다. 작은 차이를 동등성으로 해석하지 않는다. 불리한 시드·사진을 빼거나 Test로 설정을 고르지 않는다.

## 8. 실행 전 통과 기준·기록

그룹·GT·분할·A/B·대조·허용 노출 목록·버전이 확정되고 검사·예제 검산·실제 입력의 짧은 전 과정 실행이 통과해야 본학습한다. 실제 임계값과 본실험 통계는 학습 후 산출한다. 문서 갱신이 데이터·코드 완료를 뜻하지 않는다.

저장할 것: manifest·해시·출처, 그룹 판정, GT 변경, A/B·대조·조건 목록, 코드/초기 가중치 버전, 실행 설정·완료 상태·last.pt·예측, 임계값·원점수·차이·통계·변경 이력. 알려진 명백한 오류 수정은 이유·시점·영향 범위를 남기고 필요한 조건을 일관되게 재평가한다.
