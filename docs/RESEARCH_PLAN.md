# 연구 및 실험 계획

확인된 사실, 앞으로 검증할 사항, 확정된 기준을 구분한다. 아직 모르는 값은 추정해서 채우지 않고 미확정으로 둔다. 중복 판정 기준과 데이터 분할 조건은 모델 성능을 보기 전에 확정한다.

## 1. 현재 확인된 사실

2026-10-27에 로컬 디렉터리를 집계했다. 집계 대상은 `train/`, `valid/`의 jpg와 각 폴더의 `_annotations.csv`다.

- 로컬에는 `train`, `valid`만 있고 `test` 디렉터리는 없다.
- 주석 형식은 YOLO txt가 아니라 CSV다. 열은 `filename,width,height,class,xmin,ymin,xmax,ymax`다.
- 클래스명은 전부 `Microplastic`이다. 숫자 클래스 ID는 파일에 없다.
- train: 이미지 577장, 주석 행 5,425. valid: 이미지 204장, 주석 행 1,701. 합계 781장.
- CSV에 있는 파일명과 디스크의 jpg 파일명이 양쪽 분할 모두 일치한다. CSV에만 있거나 디스크에만 있는 파일은 0건이다.
- 주석에 등장하는 이미지의 박스 수는 최소 1개다. 좌표가 이미지 밖이거나 너비·높이가 0 이하인 박스는 0건이다.
- 한 변의 길이가 5px 이하인 박스는 train 15개, valid 11개다.
- 주석상 크기는 valid 전체가 563×537이다. train은 5,419행이 563×537이고, 6행이 353×336이다. 353×336인 파일은 `d--1`, `d--2`, `d--3`, `d--4` 네 장이다.
- 파일명 781개 모두 `.rf.`를 포함한다. `.rf.` 앞 토큰은 `{접두}--{번호}-_jpg` 또는 `{번호}_jpg`다. 관찰된 접두는 `a`, `b`, `c`, `d`, `f`, 그리고 접두 없음이다.
- 이 토큰 규칙으로 번호를 세면 train 198개, valid 149개이고, 그중 147개가 양쪽에 있다. train에서 같은 번호가 파일을 둘 이상 가진 경우는 180개다.
- 접두별 이미지 수는 train이 없음 124, `f` 159, `d` 82, `a` 76, `b` 72, `c` 64다. valid는 `c` 135, `f` 26, `a` 24, `d` 17, `b` 2다.
- 같은 분할 안에서 `.rf.` 앞 문자열이 같은 파일은 없다. train과 valid의 `.rf.` 앞 문자열 교집합도 0이다.
- 파일 바이트 SHA-256 일치는 0쌍이다. 781장 모두 디코딩되고 실제 크기와 주석 크기가 같다(2026-11-03, [REPORT_01.md](REPORT_01.md)).
- 사람 검토와 탐지 성능 결과는 없다.
- `original/`과 `train/`, `valid/`는 파일 783개의 경로별 SHA-256이 모두 같다(2026-11-06).
- 로컬 파일 합계 26,226,182바이트는 Kaggle `imtkaggleteam/microplastic-dataset-for-computer-vision` v1의 `totalBytes`와 같다. Kaggle 표기는 CC0이고 제작자는 "Panats MP Project"다(2026-11-06).
- 다운로드 날짜와 원본 압축파일 해시는 기록되어 있지 않다.

로컬 파일은 jpg 781개와 CSV 2개, 합계 783개이므로 공개 페이지의 783 files는 이 합계일 가능성이 높다. 공개 페이지의 파일 목록을 직접 보지는 못했다. 파일명의 같은 번호가 동일 원본인지는 확인하지 않았다. 번호 집계는 중복 판정이 아니라 후보를 만들기 위한 관찰이다.

## 3. 중복 감사 기준

### 완전 중복

SHA-256이 동일한 파일을 완전 중복으로 판정한다. 툴킷은 디코딩한 RGB 픽셀의 SHA-256을 쓰므로 파일 바이트 기준과 구분해 기록한다. 픽셀 기준 결과는 아직 없다.

### 유사 이미지

자동 유사도로 후보를 탐색하고 사람이 검토한다. 전역 pHash와 dHash는 배경의 영향이 커서 그 결과만으로 판단하지 않는다. 입자 영역과 박스 배치 같은 보조 신호와 회전·반전·크롭 탐지 성능은 [ROADMAP.md](ROADMAP.md) 6단계에서 정한다.

### 그룹 확정

동일 원본의 복사·변형으로 판단한 이미지를 같은 그룹으로 묶는다. 자동 유사도나 파일명 번호만으로 그룹을 확정하지 않는다. 시료 ID가 없으면 "같은 시료", "같은 접시"라고 쓰지 않는다.

1차 판정 값은 `same`, `different`, `uncertain`이다. 참고 캡처의 확정, 비중복, 미확정에 각각 대응한다. 팀원 1은 1차 판정과 근거까지 작성하고, 최종 그룹은 팀원 2가 확정한다.

### 확정 시점

중복 판정 기준과 그룹 목록은 모델 성능 비교 전에 확정한다.

## 4. 비교 실험

성능 비교에 쓸 분할은 세 가지다.

- 공식 분할: 받은 train/valid를 유지하는 참고 기준선
- 이미지 단위 분할: 동일 데이터 풀에서 이미지별 무작위 배정
- 그룹 단위 분할: 동일 그룹이 서로 다른 분할에 걸치지 않도록 배정

세 조건의 학습·평가 절차는 같은 기준을 쓴다. 공식 분할은 참고 기준선이다.

### 미확정 사항

아래 기본안은 팀 매뉴얼에 적힌 제안값이다. 담당자가 확인해 8절에 기록하기 전까지 확정값이 아니다.

| 항목 | 매뉴얼 기본안 | 결정 담당 |
|---|---|---|
| 반복 횟수 | O 1회, R·G 각 3회. 8절의 조건별 3회와 달라 합의가 필요하다 | 팀 |
| R·G 분할 비율 | 대략 70/15/15. G는 그룹 수 기준이라 이미지 비율이 달라질 수 있다 | 팀원 2 |
| O의 test | 없음. 제공 분할에 test가 없어 툴킷으로 목록을 만들 수 없다. [TEAM_AGENDA.md](TEAM_AGENDA.md) 안건 2 | 학습 담당, 팀원 2 |

| 후보 탐색 옵션 | 툴킷 dHash 거리 5는 보편 기준이 아니다. 보조 신호는 미정이다 | 팀원 1, 팀원 2 |

## 5. 평가 기준

- 주요 지표: mAP@50:95
- 보조 지표: mAP@50, Precision, Recall
- 각 조건 3회 반복 후 평균 및 표준편차 보고
- valid로 모델 선택, test로 최종 평가
- test 결과로 설정을 조정하지 않는다

3회 반복의 보고 형식은 평균과 표준편차로 확정되어 있다. 반복마다 분할 seed와 학습 seed 중 무엇을 바꾸는지는 4절의 미확정 항목이며, 본 실험 전에 결정 기록에 남긴다.

## 6. 해석 시 주의사항

분할 간 점수 차이에는 평가 데이터의 난이도와 구성 차이도 포함된다. 차이 전체를 중복 노출 효과로 해석하지 않는다.

valid에 `c--` 파일명 이미지가 135장으로 몰려 있는 것은 구성 차이의 후보이다. 이 분포가 난이도 차이인지는 감사와 평가 데이터 구성을 본 뒤에 판단한다.

공식 valid는 `c` 접두가 66%이고 접두 없는 이미지가 0장이다. O의 점수를 R·G와 비교할 때 이 한계를 함께 적는다.

그룹이 대부분 한 장이면 R과 G의 차이는 무작위 배정 차이에 가까워진다. 이 경우 점수 차이로 RQ2에 답할 수 없다. 3회 반복만으로 통계적 유의성을 확정하지 않는다.

Kaggle 데이터와 논문 저장소 데이터가 같다고 확인되기 전에는 논문 수치와 직접 비교하지 않는다.

## 7. 대안

중복이 거의 없거나 독립 그룹이 부족하면, 감사 결과를 보고하고 통제된 중복 노출 실험의 실행 가능성을 검토한다. 이 판단 기준은 후보 판정 전에 정한다([TEAM_AGENDA.md](TEAM_AGENDA.md) 안건 3).

test를 만드는 규칙이 확정되기 전에는 5절의 최종 평가를 실행하지 않는다. 그 전까지의 학습은 파이프라인이 끝나는지 보는 짧은 시험으로 한정한다.
