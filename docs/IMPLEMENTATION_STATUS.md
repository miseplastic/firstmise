## 실행 코드 격차

현재 `experiment/run_training.py`의 RUNS는 R/G 각 3개다. `experiment/build.py`는 과거 그룹 처리·R/G 분할을 재생성한다. 새 노출 교체 조건·최종 판정·고정 A/B를 구현한 것으로 취급하지 않는다. 실행 가능한 새 명령은 구현·검산 후 문서에 추가한다. 존재하지 않는 명령을 미리 안내하지 않는다.
