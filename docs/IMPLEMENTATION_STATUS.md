## 실행 코드 격차

`run_training.py`는 새 노출 실험, 이전 R/G는 `run_legacy_rg.py`로 분리했다. `build.py`는 과거 R/G 생성기다. 새 `exposure/prepare.py`는 최종 사람이 검수한 CSV·근거를 입력받아 네 조건을 생성하며 그룹/A-B·대조를 임의로 결정하지 않는다. 템플릿은 승인 false이고 최종 입력은 아직 저장소에 없다.

서버 진입 명령·자료 계약·결과 열·중단/재실행은 [experiment/README.md](../experiment/README.md). 서버별 경로·계정·상세 실행 기록은 저장소에 새로 올리지 않고 로컬에서 보관한다. CPU 테스트는 실제 학습을 모의 실행했으며 새로운 GPU 학습 성공을 뜻하지 않는다.
