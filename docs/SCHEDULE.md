## 실행 규칙

이전 환경·학습 로그가 충분하고 조건이 비슷하면 시간 측정 학습을 다시 돌릴 필요는 없다. GPU의 이번 사용 가능 시간은 새로 확인한다. 기간 내 12회와 평가가 불가능하면 11/26에 자원·순서를 조정한다.

분할/A-B는 11/27 고정, 수정 GT로 대조 매핑은 11/30 확정한다. 새 선택 대조는 검수한다. 실제 입력 전 과정 확인은 최종 목록 이후에 진행한다. 보류·오류는 발견 즉시 공유한다. 같은 날의 취합본 마감까지 자료를 쌓아두지 않는다.
