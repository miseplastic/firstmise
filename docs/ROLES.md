## 병목을 줄이는 방법

그룹 확정 전에도 임시 자료로 코드·검산·기록을 진행한다. 같은 소량의 예시로 검수 기준을 맞춘 뒤 작은 묶음으로 분담하고 입자 수·난이도·남은 코드 작업에 따라 조정한다. 고정 검수 비율은 두지 않는다.

명확한 사진·수정 반영은 박도현과 양현준이 교차 확인하고 어려운 판단·불일치만 박준현에게 모은다. 모든 사진을 다시 한 사람에게 검수시키지 않는다. 코드 구현 책임은 서승덕에게 있으며 박도현은 기존 코드 검토·예제 검산을 돕는다. 양현준에게 신규 학습/평가 코드 개발을 맡기지 않는다.

각 담당자가 자기 근거를 올리고 양현준은 빠진 근거·중복/상충 요청을 취합한다. 문서 판정의 원 작성자와 기록 정리자는 구분한다. 확인자는 자신의 확인 범위를 남긴다.
