### 📋 팀원1 기여도 확인 및 수정용 표

> **⚠️ 안내:** 아래 표는 저장소(Repo) 기록을 기준으로 추정한 초안입니다. 실제 수행하신 내용과 다를 수 있으니 반드시 직접 확인 후 수정해 주세요.
> - **분류 기준:** "완전 위임"과 "수정 받음"은 **실제로 누가 초안을 썼는지**를 기준으로 나눕니다.
> - **주의 사항:** 분류가 애매하다면 **'AI에게 완전히 맡김' 쪽으로 분류하는 것이 안전**합니다. (기준 위반 시 과소 기재만 문제될 뿐, 과대 기재는 문제가 되지 않습니다.)

| 구분 | 내용 | 사람이 한 일 |
| :--- | :--- | :--- |
| **AI에게 완전히 맡김** | `scripts/` 데이터 변환·중복 탐색·점검 스크립트 작성<br>*(build_dataset_work.py, find_duplicates.py, check_data_bundle.py 등)* | 실행, 결과 수치 확인 |
| **AI에게 완전히 맡김** | 툴킷 오버레이와 중복 후보를 보고 판정 예시 작성<br>*(WORKLOG 11/0x 기록)* | 예시 검토 |
| **AI에게 수정 받음** | `docs/` 문서 구성·문장 정리<br>*(README, ROADMAP, REPORT_01, TEAM_AGENDA)* | 내용과 수치 결정 |
| **AI에게 수정 받음** | 중간발표 슬라이드 n~m쪽 *(해당되는 경우에만 작성)* | 초안 작성 |
| **AI 미사용** | 상자 검토, 중복 1차 판정<br>*(label_review.csv, pair_review.csv)* | 전부 |
