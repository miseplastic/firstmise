# 작업 현황과 변경 기록

## 2026-11-26 실행·평가 구현

- 확인한 서버 YOLO commit·초기 가중치를 고정한 새 실행기와 GPU export worker를 추가했다.
- 검수 완료 CSV/근거로 네 조건을 준비하고 해시·그룹 경계·대조·반전·실행 상태를 검사한다. 사람의 실제 검토를 자동 승인하지 않는다.
- 계수·FP/FN·Val 임계값·A/B·그룹 부트스트랩·시드 집계를 구현했다. 공식 YOLO 매칭/AP와의 대조는 GPU worker에 포함했다.
- 기존 R/G 실행기는 run_legacy_rg.py에 보존했다. 실제 GT·그룹 판정·과거 목록은 변경하지 않았다.
- CPU 합성 테스트17개 통과. 학습 호출은 모의 실행. 실제 서버 pilot·새 본학습·최종 데이터 검수는 미완료다.
- 기존 환경·시간 확인에는 사용자 제공 출력을 활용했다. 서버별 경로·계정·상세 Job 기록은 로컬 보관하며 저장소 변경에는 포함하지 않는다.
